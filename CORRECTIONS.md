# Corrections and version history

Version 0.1.0, admitted October 25, 2026. Not peer reviewed.

Report suspected errors through the repository issue tracker.
Jeff Kline is responsible for assessing reports and maintaining this record.

Corrections will name the affected version and claim, explain the error and its
impact, and link the repair. A material mathematical or attribution change will
receive a new version, fresh checks appropriate to its scope, and a new archive.
Public tags and archived files will never be silently replaced or moved.

If a result must be withdrawn, the living README and this record will display
the withdrawal, its reason, and the affected versions. The original archive
will remain identifiable with a linked notice. Superseded versions will link
both backward to their predecessors and forward to the replacement.
